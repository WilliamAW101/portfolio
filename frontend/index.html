Featured Projects

Penni the Spider Robot

My role for this project was the low-end software developer, as well as the project lead. Penni is a autonomous quadruped that will walk towards and pick up green blocks using her magnetic arm mounted below her.

CragTag

CragTag is a social media rockclimbing app. My role in this project was the project lead. backend developer, and database. The webapp supports live notifications using socket.io, AWS for storing images, and refresh tokens for authentication.

CloudVault

CloudVault is a containerized file uploader using Chainguard Images for minimal, secure environments. It secures data with HTTPS, SSL certificates, and persistent storage, ensuring safe file management with Docker. My role was the primary back-end developer using flask. I was also in charge of the DevOps for deploying via docekr.
